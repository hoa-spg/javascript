Lektion 1.3 — Teil 1: Sprachgrundlagen

Arrays

JavaScript ca. 90 min Grundlagen

Lernziele

  • Arrays erstellen und ihre Eigenschaften kennen
  • Mit for … of und for … in über Arrays iterieren
  • Elemente mit push, pop, unshift, shift, splice und slice einfügen, entfernen und ausschneiden
  • Den Spread-Operator ... verwenden
  • Die Callback-Funktionen forEach, map, filter, find und reduce einsetzen
  • Wissen, welche Methoden das Original verändern und welche ein neues Array liefern

1 — Arrays

Arrays sind

  • geordnete Listen von Werten,
  • dynamisch vergrößerbar,
  • können unterschiedliche Datentypen enthalten,
  • Objekte!
Beispiel JavaScript 
const array = ["a", 7, true]; // [ 'a', 7, true ]

Die Länge eines Arrays a erhält man über die Eigenschaft a.length.

2 — Arrays erstellen

Array-Literal JavaScript 
const numbers = [1, 2, 3];
Konstruktor JavaScript 
const numbers = new Array(1, 2, 3);
Leeres Array JavaScript 
const empty = [];
Leeres Array mit n Plätzen JavaScript 
const a = new Array(n);
💡
Literal bevorzugen

In der Praxis verwendet man fast immer die Literal-Schreibweise [ … ]. Vorsicht: new Array(3) erzeugt ein leeres Array mit drei Plätzen, new Array(3, 4) dagegen ein Array mit den Werten 3 und 4.

3 — Über Arrays iterieren

Iteratoren:

  • a.values(): Werte des Arrays
  • a.keys(): Schlüssel (Indizes) des Arrays
  • a.entries(): (Index, Wert)-Paare
Iteration über die Werte: for … of JavaScript 
const a = ['a', 'b', 'c', 'd'];
for (const x of a) {
  console.log(x);
}
// Ausgabe: a, b, c, d
Iteration über die Schlüssel: for … in JavaScript 
const a = ['a', 'b', 'c', 'd'];
for (const x in a) {
  console.log(x);
}
// Ausgabe: 0, 1, 2, 3
ℹ
Merkhilfe
of → die Werte („Elemente of the array“), in → die Indizes (Schlüssel). Für Arrays braucht man fast immer for … of.

4 — Grundlegende Funktionen

Beispiele mit const array = ["a", 7, true]:

MethodeWirkung
array.push(x)hängt x am Ende an
array.pop()entfernt das letzte Element und gibt es zurück
array.unshift(x)fügt x am Anfang ein
array.shift()entfernt das erste Element und gibt es zurück
array.at(index)wie array[index], erlaubt aber auch negative Indizes (at(-1) = letztes Element)
array.concat(array2)verändert nichts, gibt das zusammengekettete Array zurück
entries() JavaScript 
Array.from(array.entries());
// liefert: [ [ 0, 'a' ], [ 1, 7 ], [ 2, true ] ]

5 — Spread-Operator ...

Syntax: [...array] bzw. [...array1, ...array2]

Spread JavaScript 
const tiere = ["Hund", "Katze", "Maus"];
const farben = ["Rot", "Blau"];

const kopie = [...tiere];
const kombiniert = [...tiere, ...farben];
const mitAnfang = ["Papagei", ...tiere];

console.log(kopie);      // ["Hund", "Katze", "Maus"]
console.log(kombiniert); // ["Hund", "Katze", "Maus", "Rot", "Blau"]
console.log(mitAnfang);  // ["Papagei", "Hund", "Katze", "Maus"]
  • Entpackt die Elemente eines Arrays an der gewünschten Stelle.
  • Sehr praktisch zum Zusammenhängen und Einfügen in neue Arrays.
  • Erzeugt ein neues Array (die Originale bleiben unverändert).

6 — Übersicht der Array-Funktionen

Viele Funktionen erwarten eine Callback-Funktion (cb), die für jedes Element aufgerufen wird.

MethodeWirkung
filter(cb)Neues Array mit allen Elementen, für die cb true ergibt
find(cb)Liefert das erste Element, für das cb true ergibt, oder undefined
findIndex(cb)Wie find, aber den Index (oder -1)
findLast(cb)Wie find, sucht aber von hinten
findLastIndex(cb)Wie findIndex, sucht aber von hinten
flat()Enthält das Array Sub-Arrays, werden diese „aufgemacht“ – das Ergebnis hat keine Sub-Arrays mehr
flatMap(cb)map und anschließend flat in einem Schritt
forEach(cb)cb wird für jedes Element aufgerufen
includes(elem)true/false: Ist das Element enthalten?
indexOf(elem) / lastIndexOf(elem)Index des (ersten/letzten) Vorkommens oder -1
join(sepStr)Verbindet alle Elemente zu einem String
keys()Iterator über die Indizes (for (let i of array.keys()))
map(cb)Neues Array mit jedem Rückgabewert von cb
pop() / push(elt)Letztes Element entfernen / Element anhängen
shift() / unshift(elt)Element mit Index 0 entfernen / am Index 0 einfügen
reduce(cb, start)Reduziert das Array auf einen einzigen Wert
reverse()Kehrt die Reihenfolge um – in place!
slice(start, end)Neues Teil-Array (Original bleibt)
some(cb)true, wenn cb für mindestens ein Element true ergibt (Gegenstück: every)
sort(cb)Sortiert in place; cb liefert <0, 0 oder >0
splice(…)Entfernt/ersetzt/fügt Elemente ein – in place
toLocaleString() / toString()String-Darstellung des Arrays (siehe auch join())
toReversed() / toSorted(cb) / toSpliced(…)Wie reverse/sort/splice, geben aber ein neues Array zurück
⚠
In place oder neu?
push, pop, shift, unshift, splice, sort und reverse verändern das Original. map, filter, slice, concat, Spread und die to…-Varianten liefern ein neues Array.

7 — splice und slice

splice

Syntax: array.splice(start, deleteCount, item1, item2, ...)

splice JavaScript 
const arr = [1, 2, 3, 4, 5];
// Entferne 2 Elemente ab Index 1 und füge 9 und 10 ein
arr.splice(1, 2, 9, 10);
console.log(arr); // [1, 9, 10, 4, 5]
  • start: Index, ab dem Elemente entfernt/ersetzt werden
  • deleteCount: Anzahl der zu entfernenden Elemente
  • Weitere Argumente: neue Elemente, die eingefügt werden

slice

Syntax: array.slice(start, end)

slice JavaScript 
const arr = [1, 2, 3, 4, 5];
// Extrahiere Elemente von Index 1 bis 3 (exklusiv)
const subArr = arr.slice(1, 3);
console.log(subArr); // [2, 3]
console.log(arr);    // [1, 2, 3, 4, 5] Original bleibt unverändert
  • start → inklusiver Startindex
  • end → exklusiver Endindex (bis, aber nicht einschließlich)
  • Gibt ein neues Array zurück → das Original-Array wird nicht verändert
  • Man kann auch nur den Start angeben: arr.slice(2) → alles ab Index 2

8 — forEach, map und reduce

forEach

Syntax: array.forEach((element, index, array) => { ... })

forEach JavaScript 
const fruits = ["Apple", "Banana", "Cherry"];
fruits.forEach((fruit, idx) => {
  console.log(`${idx}: ${fruit}`);
});
/* Ausgabe:
0: Apple
1: Banana
2: Cherry
*/
  • Iteriert über jedes Element des Arrays.
  • Der Callback erhält element, optional index und array.
  • Gibt keinen Wert zurück → nur für Seiteneffekte (z. B. Ausgabe) geeignet.
  • Kann nicht vorzeitig abbrechen (kein break).
ℹ
Template-Strings
`${idx}: ${fruit}` ist ein Template-String (mit Backticks). Ausdrücke in ${ } werden direkt in den Text eingesetzt.

map

Syntax: array.map((element, index, array) => { ... })

map JavaScript 
const numbers = [1, 2, 3, 4, 5];
const squares = numbers.map(num => num * num);
console.log(squares); // [1, 4, 9, 16, 25]
console.log(numbers); // [1, 2, 3, 4, 5] Original bleibt unverändert
  • Erstellt ein neues Array mit den Ergebnissen der Callback-Funktion.
  • Der Callback erhält element, optional index und array.
  • Das Original-Array bleibt unverändert.
  • Ideal, um Transformationen auf Arrays anzuwenden.

reduce

Syntax: array.reduce((accumulator, currentValue) => ..., initialValue)

reduce JavaScript 
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((acc, val) => acc + val, 0);
console.log(sum); // 15
  • accumulator → sammelt das Ergebnis
  • currentValue → aktuelles Array-Element
  • initialValue → Startwert für den Akkumulator
  • Reduziert das Array auf einen einzigen Wert.
SchrittaccvalRückgabe
10 (Startwert)11

46410
510515

Häufige Fehler

Fehler: for … in statt for … of

for (const x in ["a", "b"]) liefert "0", "1" – die Indizes als Strings.

Für die Werte for … of verwenden.

Fehler: map ohne Rückgabewert

numbers.map(n => { n * 2 }) ergibt [undefined, undefined, …].

Mit geschweiften Klammern braucht es return: n => { return n * 2; } – oder Kurzform n => n * 2.

Fehler: splice und slice verwechselt

arr.splice(1, 3) sollte eine Kopie liefern, hat aber das Original verändert.

slice = Ausschnitt kopieren (Original bleibt), splice = im Original entfernen/einfügen.

Aufgaben

In allen Aufgaben sind zwei Arrays mit Strings gegeben. Bearbeiten Sie jede Aufgabe unabhängig voneinander und starten Sie jeweils mit diesen Arrays:

Startcode JavaScript 
const tiere = ["Hund", "Katze", "Maus", "Pferd"];
const farben = ["Rot", "Blau", "Gruen", "Gelb"];
Aufgabe 1 Elemente lesen, entfernen, anhängen
  1. Erstes und letztes Element ausgeben: Geben Sie das erste Tier und die letzte Farbe auf der Konsole aus.
  2. Ein Element am Ende entfernen: Entfernen Sie das letzte Tier aus tiere und geben Sie das entfernte Element aus.
  3. Ein Element dranhängen: Hängen Sie die Farbe "Lila" ans Ende von farben.
Aufgabe 2 Einfügen, entfernen, zusammenhängen
  1. Ein Element am Anfang einfügen: Fügen Sie "Papagei" am Anfang von tiere ein.
  2. Mehrere Elemente entfernen: Entfernen Sie aus tiere ab Index 1 genau zwei Elemente.
  3. Zwei Listen zusammenhängen: Erzeugen Sie ein neues Array alleWoerter, das zuerst alle Tiere und danach alle Farben enthält.
  4. Eine Liste in eine andere einfügen: Fügen Sie farben in tiere ab Index 2 ein (ohne etwas zu löschen).
Aufgabe 3 slice und splice
  1. Teilarray mit slice erzeugen: Erzeugen Sie aus tiere ein neues Array mittlereTiere, das nur Katze und Maus enthält. Das Original-Array darf nicht verändert werden.
  2. Mit splice ersetzen statt nur entfernen: Ersetzen Sie in farben ab Index 1 zwei Elemente durch Lila und Orange. Geben Sie danach das veränderte Array aus.
Bonus map, filter, reduce

Erzeugen Sie mit map ein Array der Wortlängen von tiere, mit filter alle Farben mit mehr als 3 Buchstaben und mit reduce die Gesamtzahl der Buchstaben aller Tiere.
