Lektion 2.1 — Teil 2: DOM & WebApps

DOM

JavaScript ca. 90 min Browser

Lernziele

  • Erklären, was das DOM ist und wie JavaScript es nutzt
  • Elemente mit getElementById, querySelector und querySelectorAll finden
  • Inhalte, Attribute und CSS-Klassen verändern
  • Elemente erzeugen, einfügen und entfernen
  • Mit addEventListener auf Benutzeraktionen reagieren

1 — Was ist das DOM?

  • DOM = Document Object Model
  • Der Browser stellt HTML als Baumstruktur aus Knoten dar.
  • JavaScript kann diesen Baum lesen und verändern.
  • Ablauf in Web-Apps: Selektieren → Verändern → Auf Events reagieren
ℹ
Bekannt aus dem HTML-&-CSS-Kurs

Den DOM-Baum hast du in den Entwicklertools (Tab Elements) schon gesehen. Jedes HTML-Element ist darin ein Objekt, auf das JavaScript zugreifen kann – der Einstiegspunkt ist das globale Objekt document.

2 — DOM-Knoten selektieren

MethodeLiefert
getElementById(...)das Element mit dieser eindeutigen ID (oder null)
querySelector(...)das erste Element, das zum CSS-Selektor passt (oder null)
querySelectorAll(...)eine Liste (NodeList) aller passenden Elemente
Selektieren JavaScript 
const title = document.getElementById('title');
const firstTodo = document.querySelector('.todo-item');
const allTodos = document.querySelectorAll('.todo-item');

console.log(allTodos.length);
💡
Dieselben Selektoren wie in CSS
querySelector versteht alle CSS-Selektoren: '#title', '.todo-item', 'nav a', 'input[type="email"]' … (bei getElementById dagegen ohne #).

3 — Inhalte und Attribute verändern

  • Inhalte: textContent, innerHTML
  • Attribute: setAttribute(...)
  • CSS-Klassen: classList.add / remove / toggle
Verändern JavaScript 
const info = document.querySelector('#info');
info.textContent = 'Speichern erfolgreich';
info.setAttribute('data-state', 'ok');
info.classList.add('success');
⚠
textContent oder innerHTML?
textContent setzt reinen Text. innerHTML interpretiert den String als HTML – mit Benutzereingaben ist das gefährlich (eingeschleuster Code, „XSS“). Im Zweifel immer textContent verwenden.

4 — Elemente erzeugen, einfügen, entfernen

  • Neue DOM-Knoten mit createElement(...)
  • Mit append, prepend oder appendChild einfügen
  • Mit remove() wieder löschen
Erzeugen und einfügen JavaScript 
const list = document.getElementById('todo-list');

const li = document.createElement('li');
li.textContent = 'DOM-Folien fertigstellen';
list.append(li);

// später
li.remove();

5 — Auf Events reagieren

  • addEventListener(...) verbindet ein Event mit einer Handler-Funktion.
  • Häufige Events: click, input, change, submit
  • Das Event-Objekt liefert Zusatzinfos (z. B. target – das auslösende Element).
Event-Handler JavaScript 
const btn = document.getElementById('save-btn');
btn.addEventListener('click', (event) => {
  console.log('geklickt auf:', event.target.id);
});

6 — Kleines Gesamtbeispiel

index.html (body) HTML 
<input id="name-input" placeholder="Dein Name">
<button id="apply-btn">Übernehmen</button>
<p id="name-output"></p>
app.js JavaScript 
const input = document.getElementById('name-input');
const output = document.getElementById('name-output');
const button = document.getElementById('apply-btn');

button.addEventListener('click', () => {
  const value = input.value.trim();
  if (value === '') {
    output.textContent = 'Bitte Namen eingeben';
    output.classList.remove('ok');
    return;
  }
  output.textContent = `Hallo ${value}!`;
  output.classList.add('ok');
});

Häufige Fehler

Fehler: Cannot read properties of null

document.getElementById('titel') liefert null – Tippfehler in der ID oder das Script läuft, bevor das Element existiert.

ID prüfen und das Script mit defer einbinden.

Fehler: querySelectorAll wie ein einzelnes Element behandeln

document.querySelectorAll('li').textContent = '…' bewirkt nichts.

Die Liste durchlaufen: for (const li of document.querySelectorAll('li')) { … }.

Fehler: Formular lädt die Seite neu

Beim submit-Event schickt der Browser das Formular ab, und alle Änderungen sind weg.

Im Handler event.preventDefault() aufrufen.

Aufgaben

Aufgabe 1 Klick-Zähler

Ein Button „+1“ erhöht bei jedem Klick eine Zahl in einem <span>. Ab 10 Klicks bekommt die Zahl per classList eine rote Farbe.

Aufgabe 2 Einkaufsliste

Ein Eingabefeld und ein Button „Hinzufügen“ erzeugen neue <li>-Elemente in einer Liste. Leere Eingaben werden ignoriert, danach wird das Feld geleert.

Aufgabe 3 Live-Zeichenzähler

Unter einer <textarea> steht „0 / 200 Zeichen“. Aktualisiere den Text bei jeder Eingabe (input-Event).

Bonus Dark-Mode-Schalter für die Demoseite

Ergänze die Demoseite aus dem HTML-&-CSS-Kurs um einen Button, der per document.documentElement.classList.toggle('dark') eine Klasse setzt. Lege im CSS für .dark dunkle Farben fest.
