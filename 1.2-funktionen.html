Lektion 1.2 — Teil 1: Sprachgrundlagen

Funktionen

JavaScript ca. 90 min Grundlagen

Lernziele

  • Funktionen deklarieren, aufrufen und in Variablen speichern
  • Den Unterschied zwischen Funktion und Methode (this) kennen
  • Arrow-Functions schreiben und lesen
  • Funktionen als Argumente (Callbacks) übergeben – und aufrufen von übergeben unterscheiden
  • Verstehen, wie JavaScript mit zu vielen, zu wenigen und fehlenden Argumenten bzw. Rückgabewerten umgeht
  • Die Grundidee von Closures erklären

1 — Funktionen

Funktionen …

  • dienen der Mehrfachverwendung und Gliederung von Code.
  • können eine (fast) beliebige Anzahl von Parametern bekommen.
  • können einen Rückgabewert haben (müssen aber nicht).
  • Innerhalb der Funktion besteht Zugriff auf den globalen Scope (Variablen, die mit const oder let deklariert wurden).
  • Eine Funktion kann selbst Parameter für eine andere Funktion sein (Callbacks, wie z. B. setTimeout(function, milliSeconds)).
  • Funktionen können einen Namen haben, aber auch anonym sein (Lambda-Functions bzw. Arrow-Functions).
Funktionsdeklaration JavaScript 
function begruessung(name) {
  return "Hallo " + name;
}

let text = begruessung("Anna");
console.log(text);
  • function startet die Funktionsdefinition
  • name ist ein Parameter
  • return gibt das Ergebnis zurück

Funktionen sind Werte

Funktionen können auch in Variablen gespeichert werden:

Funktionsausdruck JavaScript 
const addiere = function(a, b) {
  return a + b;
};

console.log(addiere(3, 4));
ℹ
Wichtig

Funktionen sind in JavaScript Werte. Man kann sie wie Zahlen oder Strings in Variablen speichern, an andere Funktionen übergeben und aus Funktionen zurückgeben.

2 — Methoden

Eine Methode ist eine Funktion, die zu einem Objekt gehört.

Methode JavaScript 
const student = {
  name: "Tom",
  sageHallo: function() {
    return "Hallo, ich bin " + this.name;
  }
};

console.log(student.sageHallo());
  • Eine Methode ist eine Funktion in einem Objekt.
  • this bezieht sich auf das Objekt, über das die Methode aufgerufen wurde.

3 — Arrow-Functions / Lambdas

Seit ES6 gibt es eine kürzere Schreibweise:

  • Weniger Schreibarbeit
  • Übersichtlicher Code
  • Besonders praktisch bei kurzen Funktionen
Arrow-Function JavaScript 
const addiere = (a, b) => {
  return a + b;
};

Noch kürzer (wenn der Rumpf nur aus einem Ausdruck besteht):

Kurzform JavaScript 
const addiere = (a, b) => a + b;
  • Links stehen die Parameter.
  • Rechts steht die Berechnung (ihr Ergebnis wird automatisch zurückgegeben).
  • Das Wort function entfällt.
  • Die Funktion selbst hat keinen Namen (sie wird hier nur in der Variablen addiere gespeichert).
SchreibweiseCode
Normalfunction(a, b) { return a + b; }
Arrow(a, b) => a + b
⚠
Arrow-Functions und this

Arrow-Functions haben kein eigenes this. Für Methoden in Objekten (wie sageHallo oben) deshalb die normale Schreibweise verwenden.

4 — Beispiel: Array sortieren mit Arrow-Function

sort mit Vergleichsfunktion JavaScript 
const zahlen = [5, 2, 9, 10, 7];

zahlen.sort((a, b) => a - b);

console.log(zahlen);

Was passiert hier?

  • sort() sortiert ein Array.
  • Die Funktion (a, b) => a - b sagt, wie sortiert werden soll:
  • Ist das Ergebnis negativ → a kommt vor b
  • Ist das Ergebnis positiv → b kommt vor a
  • Ist das Ergebnis 0 → die Reihenfolge bleibt gleich

Warum brauchen wir das? Ohne diese Funktion würde JavaScript Zahlen wie Texte sortieren: [10, 2, 5, 7, 9] (weil der Text „10“ mit „1“ beginnt).

5 — Beispiel: Alert mit Verzögerung

Variante 1 (falsch):

falsch JavaScript 
setTimeout(alert("Hello World"), 3000);
  • alert("Hello World") wird sofort ausgeführt.
  • Das Ergebnis (undefined) wird an setTimeout übergeben.
  • Es gibt keine Verzögerung.

Variante 2 (richtig):

richtig JavaScript 
setTimeout(() => alert("Hello World"), 3000);
  • Es wird eine Funktion übergeben.
  • Diese Funktion wird erst nach 3000 ms ausgeführt.
  • Der Alert erscheint also nach 3 Sekunden.
💡
Merke

Mit () wird eine Funktion aufgerufen.
Ohne () wird eine Funktion übergeben.

6 — Parameter und Argumente

Für die Sprache selbst ist es egal, ob der Aufrufer die „richtige“ Anzahl an Argumenten mitgibt. Beispiel ohne Parameter, aber dennoch werden Argumente übergeben – sie sind über das spezielle Objekt arguments erreichbar:

zu viele Argumente JavaScript 
function f() {
  for (let i = 0; i < arguments.length; i++) {
    console.log(i, arguments[i]);
  }
}

f(23, "georg", new Date());
Ausgabe Text 
0 23
1 georg
2 2023-10-18T20:28:55.244Z

Hier werden „zu wenige“ Argumente übergeben, siehe undefined in der Ausgabe:

zu wenige Argumente JavaScript 
function f(a, b, c) {
  console.log(a);
  console.log(b);
  console.log(c);
  for (let i = 0; i < arguments.length; i++) {
    console.log(i, arguments[i]);
  }
}

f(23, 3.14159);
Ausgabe Text 
23
3.14159
undefined
0 23
1 3.14159

Kein Rückgabewert

Gleiches gilt für den Rückgabewert einer Funktion:

kein return JavaScript 
function f() {}

const y = f();
console.log(y);
Ausgabe Text 
undefined

7 — Eine Funktion als Argument

Funktion als Parameter JavaScript 
function f(funcPar, actualPar) {
  funcPar("The answer:", actualPar);
}

f(console.log, 42);

Der Parameter funcPar ist hier die Funktion console.log. Ausgabe:

Ausgabe Text 
The answer: 42

8 — Closures

Grundidee

  • Eine Closure ist eine Funktion plus ihr umgebender Scope.
  • Die innere Funktion merkt sich die Variablen der äußeren Funktion.
  • Das funktioniert auch dann, wenn die äußere Funktion schon beendet ist.
Closure JavaScript 
function makeGreeter(name) {
  return function() {
    return "Hallo " + name;
  };
}

const greetAnna = makeGreeter("Anna");
console.log(greetAnna()); // Hallo Anna

Beispiel: Counter

Counter JavaScript 
function makeCounter() {
  let count = 0;
  return () => {
    count++;
    return count;
  };
}

const counter1 = makeCounter();
const counter2 = makeCounter();

console.log(counter1()); // 1
console.log(counter1()); // 2
console.log(counter2()); // 1
  • Jeder Aufruf von makeCounter() erzeugt eine eigene Closure mit eigenem count.
  • count ist von außen nicht direkt zugreifbar – eine Art „private Variable“.

Häufige Fehler

Fehler: Funktion aufgerufen statt übergeben

button.addEventListener('click', speichern()) führt speichern sofort aus und übergibt das Ergebnis.

Die Funktion selbst übergeben: addEventListener('click', speichern) oder () => speichern().

Fehler: return vergessen

Eine Funktion berechnet etwas, liefert aber undefined.

Ohne return gibt jede Funktion undefined zurück. Bei Arrow-Functions mit geschweiften Klammern ist return ebenfalls nötig.

Fehler: sort() ohne Vergleichsfunktion für Zahlen

[10, 2, 5].sort() ergibt [10, 2, 5].

Zahlen immer mit Vergleichsfunktion sortieren: sort((a, b) => a - b).
