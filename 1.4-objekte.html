Lektion 1.4 — Teil 1: Sprachgrundlagen

Objekte & Klassen

JavaScript ca. 90 min Grundlagen

Lernziele

  • Klassen mit Konstruktor und Methoden schreiben und Objekte mit new erzeugen
  • Private Felder mit # einsetzen
  • Vererbung mit extends und super umsetzen
  • Objekte direkt als Object Literal schreiben und Eigenschaften dynamisch hinzufügen/entfernen
  • Objekte mit JSON.stringify und JSON.parse in JSON umwandeln und zurück

1 — Objekte als Instanzen von Klassen (wie in Java)

  • Seit ES6 gibt es die class-Syntax (ähnlich zu Java).
  • Konstruktor mit constructor() (es gibt nur einen Konstruktor).
  • Methoden stehen im Klassenrumpf.
Klasse Person JavaScript 
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    return "Hi, ich bin " + this.name;
  }
}

const p = new Person("Anna", 30);
console.log(p.greet());

2 — Private Attribute mit # (seit ES2022)

  • Mit # definierte Felder sind wirklich privat.
  • Zugriff ist nur innerhalb der Klasse möglich.
  • Kein Zugriff von außen (auch nicht per this["..."]).
  • Anders als private in Java: rein sprachlich erzwungen.
Privates Feld JavaScript 
class Person {
  #age; // privates Feld (Deklaration erforderlich)

  constructor(name, age) {
    this.name = name;
    this.#age = age;
  }

  getAge() {
    return this.#age;
  }
}

const p = new Person("Anna", 30);
console.log(p.getAge()); // OK
console.log(p.#age);     // Fehler!

3 — Vergleich zu Java

Ähnlich

  • Klassen, Konstruktoren, Methoden
  • Objekte mit new

Unterschiede

  • Keine Typdeklarationen
  • Kein echtes klassenbasiertes Modell, sondern prototypbasiert
  • Methoden sind Funktionen
Java vs. JavaScript JavaScript 
// Java
Person p = new Person("Anna", 30);

// JavaScript
const p = new Person("Anna", 30);
ℹ
Prototypbasiert?

Intern ist eine JavaScript-Klasse nur eine bequeme Schreibweise: Jedes Objekt hat einen Verweis auf ein anderes Objekt (seinen Prototyp), von dem es Methoden „erbt“. class erzeugt diese Verknüpfung automatisch.

4 — Vererbung

  • extends erzeugt eine Unterklasse.
  • super(...) ruft den Konstruktor der Oberklasse auf.
  • super.methode() ruft eine Methode der Oberklasse auf.
  • super(...) muss im Konstruktor vor this stehen!
Oberklasse JavaScript 
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return "Hallo " + this.name;
  }
}
Unterklasse JavaScript 
class Student extends Person {
  constructor(name, matrikelNr) {
    super(name); // Aufruf Oberklasse
    this.matrikelNr = matrikelNr;
  }

  greet() {
    return super.greet() +
      " (Matrikel: " + this.matrikelNr + ")";
  }
}

const s = new Student("Anna", 12345);

5 — Direkte Objektschreibweise (Object Literal)

  • Objekte sind auch ohne Klasse definierbar.
  • Sie bestehen aus Schlüssel-Wert-Paaren.
  • Sehr häufige Schreibweise in JS.
Object Literal JavaScript 
const person = {
  name: "Anna",
  age: 30,
  greet: function() {
    return "Hi, ich bin " + this.name;
  }
};

console.log(person.name);
console.log(person.greet());

Dynamische Eigenschaften

Eigenschaften können jederzeit hinzugefügt oder entfernt werden – anders als in Java!

Eigenschaften ändern JavaScript 
const person = { name: "Anna" };
person.age = 30;           // hinzufügen
delete person.name;        // entfernen
person["city"] = "Berlin"; // alternative Syntax

6 — JSON (JavaScript Object Notation)

  • Reines Datenformat (keine Funktionen!)
  • Wird für den Datenaustausch verwendet (z. B. REST-APIs)
  • Sehr ähnlich zu Object Literals
JSON JavaScript 
// JSON (String)
const jsonText = '{"name": "Anna", "age": 30}';

const obj = JSON.parse(jsonText);
const backToJson = JSON.stringify(obj);
JSONJS-Objekt
nur Daten (Text)Daten + Methoden
Schlüssel immer in doppelten AnführungszeichenSchlüssel ohne Anführungszeichen möglich
JSON.parse(text) → ObjektJSON.stringify(obj) → Text

Häufige Fehler

Fehler: this vor super()

Im Konstruktor einer Unterklasse wird this.x = … vor super(…) gesetzt – das wirft einen ReferenceError.

super(…) immer als erste Anweisung im Konstruktor aufrufen.

Fehler: new vergessen

const p = Person("Anna", 30) wirft TypeError: Class constructor Person cannot be invoked without 'new'.

Objekte aus Klassen immer mit new erzeugen.

Fehler: Methoden gehen bei JSON verloren

Nach JSON.parse(JSON.stringify(person)) fehlt greet().

JSON speichert nur Daten. Methoden (und private Felder) werden nicht übertragen.

Aufgaben

Aufgabe 1 Klasse Konto
  1. Erstellen Sie eine Klasse Konto mit dem privaten Feld #pin und den öffentlichen Feldern username und balance. Methoden:
    • checkPin(eingabe) → true/false
    • einzahlen(betrag) → wirft einen Error bei ungültigem Parameter
    • toString() → String-Darstellung des Objekts
    • toPublicJSON() → JSON nur mit öffentlichen Daten (also ohne #pin)
  2. Erzeugen Sie ein Objekt konto = new Konto('sam2026', 1234) und testen Sie checkPin(1111) sowie checkPin(1234).
  3. Testen Sie die einzahlen-Methode. Nur gültige Parameter sollen akzeptiert werden.
  4. Erstellen Sie eine toString()-Methode, die den Benutzernamen ausgibt, z. B. Benutzer: sam2026. Verwenden Sie dafür Template-Strings: `Variable: ${abc}`
  5. Entwickeln und testen Sie die Methode konto.toPublicJSON(). Hier muss mit den öffentlichen Attributen ein neues Objekt erstellt werden!
Aufgabe 2 Profil einer Lernplattform

Eine Lernplattform speichert zu jedem Teilnehmer ein Profil:

Startcode JavaScript 
const profil = {

  punkte: 42,
  aktiv: true,
  kontakt: {
    email: "sam@example.com",
    ort: "Graz"
  },
  interessen: ["JavaScript", "Web", "UI"]
};
  1. Geben Sie username, punkte und die Stadt in einem Satz auf der Konsole aus.
  2. Ergänzen Sie das Objekt um level mit dem Wert "Beginner". Erhöhen Sie danach punkte um 8.
  3. Entfernen Sie die Eigenschaft aktiv mit delete. Prüfen Sie anschließend mit console.log, ob sie noch existiert.
  4. Wandeln Sie profil mit JSON.stringify in JSON um und speichern Sie das Ergebnis in profilJson. Konvertieren Sie es danach mit JSON.parse zurück in profilKopie.
  5. Fügen Sie profilKopie eine neue Eigenschaft letzterLogin hinzu (z. B. "2026-03-11").

Leiten Sie von Konto eine Klasse Sparkonto mit zusätzlichem Feld zinssatz ab. Überschreiben Sie toString() so, dass es super.toString() verwendet und den Zinssatz anhängt.
